# icons 目录说明

## 职责

背包、快捷栏与掉落物使用的分类图标图集。

## 当前内容

- `item_farming_icons.png`：原始像素图或参考图；实际裁切与动画配置位于对应资源或场景。
- `item_farming_plants.png`：植物种子与果实图集，32×240像素，16×16网格；左列为种子袋，右列为对应果实/植物。当前土豆、胡萝卜和药草物品定义已引用此图集。
- `item_food_icons.png`：原始像素图或参考图；实际裁切与动画配置位于对应资源或场景。
- `item_general_icons.png`：原始像素图或参考图；实际裁切与动画配置位于对应资源或场景。
- `item_tool_material_icons.png`：原始像素图或参考图；实际裁切与动画配置位于对应资源或场景。

## 维护规则

- 只放原始素材；不要手改 import 文件。像素图保持最近邻过滤，组合图集先确认单元尺寸和 Terrain/动画排列。
- 文件使用英文蛇形命名；同类文件保持统一前缀，避免含糊名称。
- 删除或移动文件前，用全项目引用搜索确认场景、资源与脚本没有依赖。
