# definitions 目录说明

## 职责

一作物一资源的定义目录，描述种子关联、生长天数、耐旱天数、收获经验、收获内容和外观场景。

## 当前内容

- `carrot.tres`：Godot 可视化资源；双击后在检查器维护具体字段和引用。
- `medicinal_herb.tres`：Godot 可视化资源；双击后在检查器维护具体字段和引用。
- `potato.tres`：Godot 可视化资源；双击后在检查器维护具体字段和引用。

## 维护规则

- 优先通过 Godot 检查器修改 tres；更换被引用资源时保持 ID 和路径稳定，并运行资源完整性测试。
- `growth_days` 至少为1；`dry_tolerance_days` 决定允许连续漏浇的天数；`harvest_experience` 可设为0关闭经验奖励。
- `harvest` 建议同时包含成品和对应种子，防止种植链永久中断。
- 文件使用英文蛇形命名；同类文件保持统一前缀，避免含糊名称。
- 删除或移动文件前，用全项目引用搜索确认场景、资源与脚本没有依赖。
