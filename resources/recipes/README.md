# 配方资源维护说明

- 每个配方位于 `definitions/`，材料与产物使用物品 ID。
- 新增配方时复制同工作站的资源，再加入 `recipe_database.tres` 的 `recipes` 数组。
- `station` 决定配方出现在工作台还是厨房。

## 字段与验收

- `ingredients` 与 `results` 都使用 `{物品ID: 数量}` 字典，数量必须是正整数。
- `effect` 只用于无法由普通产物表达的附加效果。
- 修改配方不会自动修改初始背包或任务条件，需要分别检查相关资源。
- 新配方加入数据库后运行资源完整性测试，确认所有物品 ID 有定义。
