# 僵尸来了也要种田

手动替换美术、调整数值和编辑场景时，请先查看 [`docs/manual_editing_guide.md`](docs/manual_editing_guide.md)。

俯视角像素风末日种田生存 RPG。当前阶段用于验证“白天经营与准备，夜晚抵御僵尸，周期性迎战尸潮”的核心循环。

## 当前可玩内容

- 角色移动与近战攻击
- 木材、石料和草药采集
- 开垦、播种、浇水、成长与收获
- 木栅栏和尖刺建造
- 普通僵尸、快速僵尸和夜间袭击
- 昼夜循环与七日尸潮
- 可自定义的9格快捷物品栏
- 24格堆叠背包与物品说明
- 可从背包直接使用消耗品
- 支持从背包拖入快捷栏、快捷槽互换与右键清空
- 栅栏和尖刺作为背包物品，通过鼠标预览、旋转并放置
- 僵尸以农舍为最终目标，途中攻击防御设施
- 农舍独立耐久、受损反馈与攻破处理
- 数据驱动的三波尸潮、波次状态、胜利判定与奖励
- 从快捷栏选择种子进行播种的多作物种田系统
- 生命与体力、冲刺、行动消耗和自然恢复
- 资源采集进度，以及石斧伐木、石镐采石的工具效率
- 维修锤、设施维修和农舍维修
- 数据驱动的第一周目标、进度、奖励与存档
- 18:00后通过床铺主动结束一天
- Esc 暂停菜单，以及暂停时保存、读取和退出
- 从背包丢弃物品、地面拾取与地面物品存档
- 选中维修锤后按 X 拆除并回收防御设施
- 炖菜提供60秒饱餐战斗增益
- 树木、矿石、工作台、料理台、床铺、农舍和防御设施拥有实体碰撞
- 可制作和放置的12格木制储物箱，支持背包双向存取与独立存档
- 饥饿随时间和冲刺下降，归零后损失生命；土豆与炖菜可补充饥饿
- 口渴生存值、脱水伤害、低状态警告，以及基地取水泵
- 击杀经验、角色等级，以及升级带来的生命、体力和伤害成长
- 数据驱动的晴朗、降雨与炎热天气，对作物浇水和口渴速度产生影响
- 防御设施三级升级：栅栏强化耐久，尖刺同时强化耐久与反伤
- 可制作与放置的简易捕兽夹，提供伤害、减速和有限触发次数
- 中文主菜单、新游戏覆盖确认、存档重置、继续游戏和退出入口
- 新游戏统一重置背包、快捷栏、任务、角色、天气、农田与全部放置物
- 默认全屏运行、逻辑分辨率自适应缩放，以及 F11 全屏切换
- 玩家角色使用48×48像素精灵表，实现四方向待机与行走显示
- 玩家砍树与锄地使用32×48动作精灵，实现四方向三帧工具动作
- 石锄制作、快捷栏工具验证、无效操作免体力消耗及完整土地开垦流程
- 世界操作改为鼠标点击或长按：工具采集、耕作播种、浇水收获与连续战斗
- 全草地开局、扩展可耕区域、土地格悬停高亮与开局石锄快捷槽
- 五份容量浇水壶、取水泵补水、用水消耗验证和四方向浇水动作
- 玩家行走与工具动作统一为3 FPS，长按操作等待完整动作结束
- 武器制作后进入背包，由玩家手动装备或放入快捷栏
- 基础养鸡模块：母鸡在基地附近活动、每日产蛋、鼠标收取并保存状态
- 角色待机、行走、锄地、砍树与浇水改用可视化 SpriteFrames 动画资源
- 母鸡显示改用独立场景与可视化 SpriteFrames 动画资源
- 木屋墙体、屋顶和门拆分为独立 TileSet，并组合为可视化房屋场景
- 母鸡与农舍改为完整独立场景，动画、碰撞、房屋图层和血条均可视化编辑
- 树木、石块、草药和地面掉落物改为独立场景，精灵、碰撞与进度条可视化编辑
- 栅栏、尖刺、捕兽夹和储物箱改为独立场景，放置预览直接复用设施外观
- 感染者外观与碰撞改为独立场景，普通和快速类型复用同一可视化结构
- 世界瓦片、耕地高亮和建筑放置统一使用32像素逻辑网格，白天不再全局染色

## 入口文件

- 启动场景：`scenes/ui/main_menu.tscn`
- 游戏场景：`scenes/game/game_world.tscn`
- 游戏流程：`scripts/core/game_controller.gd`
- 项目结构规范：`docs/project_structure.md`
- 命名规范：`docs/naming_conventions.md`
- 可视化资源规范：`docs/visual_authoring_guidelines.md`
- 物品数据库：`resources/items/item_database.tres`
- 单件物品：`resources/items/definitions/*.tres`（图标、分类、堆叠和玩法参数均可在检查器修改）
- 作物数据库：`resources/crops/crop_database.tres`（生长天数、收获物和作物场景均可视化配置）
- 配方数据库：`resources/recipes/recipe_database.tres`（材料、产物和工作站可视化配置）

## 原型操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| Shift | 冲刺并持续消耗体力 |
| E | 使用工作台、床铺、储物箱、取水泵等设施 |
| 鼠标左键/长按 | 对目标使用工具、耕作或连续攻击 |
| T | 测试用：时间前进两小时 |
| R | 使用绷带 |
| F | 食用炖菜 |
| K / L | 保存 / 读取 |
| B | 打开 / 关闭背包 |
| Esc | 暂停；或关闭当前界面 |
| F11 | 切换全屏与窗口模式 |
| X | 选中维修锤时拆除附近防御设施 |
| U | 选中维修锤时升级附近防御设施 |
| 1—9 | 激活对应快捷栏槽位 |
| 鼠标左键 | 选择快捷物品；放置模式下确认建造 |
| R | 放置模式下旋转建筑 |
| 鼠标右键 / Esc | 取消放置 |
