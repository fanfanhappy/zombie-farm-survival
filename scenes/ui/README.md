# ui 目录说明

## 职责

菜单、HUD、背包、快捷栏和储物界面场景。

## 当前文件

- `backpack_ui.tscn`：背包窗口采用左侧物品网格、右侧详情的横向布局，固定在快捷栏上方并保留滚动扩容能力。
- `character_status_hud.tscn`：可视化场景；节点结构、外观引用、碰撞和默认参数在编辑器中维护。
- `game_hud.tscn`：可视化场景；节点结构、外观引用、碰撞和默认参数在编辑器中维护。
- `game_menus.tscn`：可视化场景；节点结构、外观引用、碰撞和默认参数在编辑器中维护。
- `hotbar_ui.tscn`：9 格快捷栏布局和当前选中物品名称。
- `inventory_ui.tscn`：可视化场景；节点结构、外观引用、碰撞和默认参数在编辑器中维护。
- `main_menu.tscn`：可视化场景；节点结构、外观引用、碰撞和默认参数在编辑器中维护。
- `settings_ui.tscn`：主菜单与暂停菜单共用的设置面板，集中显示操作说明和全屏切换。
- `storage_ui.tscn`：可视化场景；节点结构、外观引用、碰撞和默认参数在编辑器中维护。

## 关联与维护

- 场景只负责节点组合和可调参数；复杂逻辑放到 scripts 对应目录。可复用对象必须是独立场景。
- 场景节点使用 PascalCase，文件使用英文蛇形命名，脚本与场景尽量同领域对应。
- 修改公共节点路径、组名、信号或资源 ID 后，必须运行两套回归测试。
- 删除文件前检查动态加载、TileSet 场景集合和存档恢复逻辑。
