# crops 目录说明

## 职责

各作物可变阶段外观子场景。

## 当前文件

- `carrot_crop_visual.tscn`：可视化场景；节点结构、外观引用、碰撞和默认参数在编辑器中维护。
- `medicinal_herb_crop_visual.tscn`：可视化场景；节点结构、外观引用、碰撞和默认参数在编辑器中维护。
- `potato_crop_visual.tscn`：可视化场景；节点结构、外观引用、碰撞和默认参数在编辑器中维护。

## 手动更换作物美术

- 根节点必须挂载 `crop_visual.gd`，生长节点按 `Stage0`、`Stage1`、`Stage2`……连续命名。
- 阶段数量不再固定为五个；增加或删除 `Stage` 节点后，系统会按编号自动分配生长进度，最后一个阶段作为成熟外观。
- 每个 `Stage` 都可以在检查器中单独修改图片、图集区域、位置、缩放和层级，不需要改代码。
- 根节点的“枯萎外观/Withered Modulate”控制枯萎颜色；枯萎时沿用最后一个阶段的图片。

## 关联与维护

- 场景只负责节点组合和可调参数；复杂逻辑放到 scripts 对应目录。可复用对象必须是独立场景。
- 场景节点使用 PascalCase，文件使用英文蛇形命名，脚本与场景尽量同领域对应。
- 修改公共节点路径、组名、信号或资源 ID 后，必须运行两套回归测试。
- 删除文件前检查动态加载、TileSet 场景集合和存档恢复逻辑。
