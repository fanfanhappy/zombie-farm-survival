# 《僵尸来了也要种田》Prototype 0.1 试玩说明

## 安装与启动

1. 下载 `zombie-farm-survival-v0.1.0-windows-x86_64.zip`。
2. 将压缩包完整解压到任意文件夹。
3. 双击 `zombie-farm-survival.exe` 启动游戏，无需安装 Godot。
4. 当前程序未购买数字签名；如果 Windows SmartScreen 弹出提示，请选择“更多信息”，核对文件名后再选择“仍要运行”。

支持 Windows 10/11 64 位系统。存档保存在系统的 Godot 用户数据目录中，覆盖或删除游戏程序不会自动清除存档。

## 推荐体验流程

1. 进入“开始新游戏”，熟悉移动、快捷栏和背包。
2. 选择斧头，砍伐树木；靠近石头时使用对应工具收集资源。
3. 将锄头放入快捷栏并选中，点击角色附近的有效草地进行开垦。
4. 选择种子点击已开垦土地播种，再选择水壶浇水。
5. 使用工作台制作物品，放置栅栏、尖刺、捕兽夹和储物箱。
6. 观察昼夜、天气、饥饿、口渴与作物成长，并尝试抵御感染者和尸潮。
7. 测试暂停菜单、保存、读取以及重新开始新游戏后的数据重置。

## 主要操作

| 按键 | 功能 |
|---|---|
| `WASD` / 方向键 | 移动 |
| `Shift` | 冲刺 |
| 鼠标左键 / 长按 | 使用工具、耕作、攻击或确认放置 |
| 鼠标右键 / `Esc` | 取消放置或关闭界面 |
| `E` | 与工作台、床铺、储物箱和取水泵交互 |
| `1`—`9` | 选择快捷栏 |
| `B` | 打开或关闭背包 |
| `R` | 使用绷带；放置时旋转物品 |
| `F` | 食用炖菜 |
| `X` / `U` | 拆除 / 升级附近防御设施 |
| `K` / `L` | 快速保存 / 读取 |
| `F11` | 切换全屏和窗口模式 |

## 当前版本说明

这是第一阶段可玩原型，重点验证种植、采集、制造、建造、防守、生存和存档循环。部分美术、动画、音效、数值平衡和农田 Terrain Set 仍会继续调整，不代表最终品质。
