# 可视化资源制作规范

## 世界网格

- 原始瓦片尺寸：`16×16` 像素。
- 世界显示倍率：`2×`。
- 逻辑网格尺寸：`32×32` 世界像素。
- 瓦片层位置：`(-16, -16)`，确保瓦片中心落在32像素网格交点。
- 耕地、高亮、鼠标命中和建筑放置必须使用 `WorldGrid` 换算，不单独写死尺寸。

## 瓦片素材

- 导入新图集前，先检查作者提供的示例图、bitmask或Terrain参考图。
- 自动拼接素材必须建立独立 `TileSet .tres`，使用 Terrain Set 手工标注连接规则。
- 不根据透明像素自动猜测 Terrain 连接关系。
- 地图中的每个用途使用独立 `TileMapLayer`，例如地面、水面、道路、耕地、装饰和碰撞。
- 水体、墙体、悬崖等随瓦片变化的阻挡区域，应在 TileSet 的 Physics Layer 中逐瓦片配置；地图绘制后碰撞自动同步，不能另建一份手工碰撞轮廓。
- 当前池塘采用“WaterLayer 铺四帧水面底图、GroundLayer 用 Grass Terrain 自动拼岸边”的双层方式；不要把动画帧的四列当成四种手动画块。
- 地面、水面、道路和围栏的初始布局直接保存在场景的 TileMapLayer 中，运行时脚本不再兜底生成，避免编辑器画面与实际运行结果不一致。

## 动画与场景

- 帧序、FPS、循环、缩放和偏移保存在 `SpriteFrames`、`AnimationPlayer`或场景节点中。
- 代码只负责选择动画状态，不直接计算精灵表帧号。
- 可交互对象应拆分主体、外观、碰撞、交互区域、状态提示和音效节点。
- 放置预览复用物体正式场景的外观，避免维护第二套预览绘图。

## 色彩与像素显示

- 白天 `CanvasModulate` 保持纯白，不改变原素材颜色。
- 清晨和黄昏只做轻微颜色过渡，夜晚使用统一蓝灰色。
- 所有像素素材使用最近邻过滤，不生成MipMap。
- 新素材优先匹配项目主调色板；明显偏色的素材先制作调色版本再接入。
