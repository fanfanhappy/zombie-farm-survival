# 模块重构审计

## 场景清理结果

2026-09-08 对 `scenes/` 全目录完成引用检查。现有场景均至少被以下入口之一使用：主场景、子场景、代码动态加载、TileSet 场景集合或自动测试。因此本轮没有可安全删除的废弃场景。

删除场景前必须同时检查 `.tscn`、`.tres`、`.gd` 与 `project.godot`。尤其不要仅凭主场景中看不到节点就删除 `TileSetScenesCollectionSource` 使用的资源点和装饰场景。

## 后续优先级

1. `game_controller.gd`：存档与世界恢复已拆到 `GamePersistence`；后续新增流程继续放入对应系统，不再回填总控制器。
2. 制作系统：配方仍为 JSON，建议迁移为一配方一资源，便于检查器添加和关联物品。
3. 放置系统：可放置场景表仍在代码中重复声明，建议并入物品定义或独立放置物数据库。
4. 任务、天气、尸潮与防御升级：仍为 JSON，可按模块依次资源化。
5. 玩家控制器：输入、生存状态、动画和攻击表现已经拆成独立场景组件。

本轮已完成作物模块资源化，移除了农田脚本中写死的作物场景映射。
