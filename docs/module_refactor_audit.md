# 模块重构审计

## 场景清理结果

2026-09-08 对 `scenes/` 全目录完成引用检查。现有场景均至少被以下入口之一使用：主场景、子场景、代码动态加载、TileSet 场景集合或自动测试。因此本轮没有可安全删除的废弃场景。

删除场景前必须同时检查 `.tscn`、`.tres`、`.gd` 与 `project.godot`。尤其不要仅凭主场景中看不到节点就删除 `TileSetScenesCollectionSource` 使用的资源点和装饰场景。

## 已完成的模块化结果

1. 物品、作物、配方、放置物、天气、任务、尸潮和防御升级均已改为可视化资源。
2. 农田不再写死作物外观场景，放置系统不再写死建筑场景和占地尺寸。
3. `GamePersistence` 负责存档组装、世界对象序列化与恢复。
4. `WorldTargetingService` 负责鼠标目标、附近交互物和防御设施查询。
5. 玩家输入、生存状态、动画与攻击表现已拆成独立组件。
6. 全部资源数据库增加交叉引用完整性测试，避免删除或改名后产生静默坏链。

存档文件继续使用 JSON 是有意保留：它属于玩家运行时数据，不是策划配置，适合跨版本迁移与人工排查。

后续新增玩法时应直接建立对应 System、Definition 和 Database，不再把职责回填到 `game_controller.gd` 或玩家总控制脚本。
