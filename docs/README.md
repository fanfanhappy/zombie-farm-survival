# docs 目录说明

## 职责

项目规范、架构决策、美术参考与维护审计的统一入口。

## 当前内容

- `default_project_architecture.md`：项目说明或规范文档。
- `module_refactor_audit.md`：项目说明或规范文档。
- `naming_conventions.md`：项目说明或规范文档。
- `project_structure.md`：项目说明或规范文档。
- `visual_authoring_guidelines.md`：项目说明或规范文档。

## 维护规则

- 文档使用 Markdown，架构或命名规则改变时同步更新关联 README 和审计报告。
- 文件使用英文蛇形命名；同类文件保持统一前缀，避免含糊名称。
- 删除或移动文件前，用全项目引用搜索确认场景、资源与脚本没有依赖。
