# farming 目录说明

## 职责

农田状态机、作物阶段显示、缺水枯萎、收获奖励与存档数据。

## 当前文件

- `crop_visual.gd`：切换五个生长阶段，并为枯萎作物应用统一视觉状态。
- `farm_plot.gd`：维护单格土地从空地、开垦、播种、生长、成熟到枯萎/收获的完整状态机。

## 关联与维护

- 一个脚本只负责一个明确职责；跨实体逻辑进入 systems，实体自身逻辑进入 world 或 actors。
- 场景节点使用 PascalCase，文件使用英文蛇形命名，脚本与场景尽量同领域对应。
- 修改公共节点路径、组名、信号或资源 ID 后，必须运行两套回归测试。
- 删除文件前检查动态加载、TileSet 场景集合和存档恢复逻辑。
- 不要改变 `PlotState` 既有枚举顺序；新增状态只能追加，否则会破坏旧存档。
